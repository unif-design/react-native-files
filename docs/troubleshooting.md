# 常见问题

通过 `status` 和 `error.reason` 判断结果。下表列出错误消息和处理方法，业务代码应使用错误类型判断，避免匹配中文文案。

| 错误消息                                    | 处理方法                                                         |
| ------------------------------------------- | ---------------------------------------------------------------- |
| `当前平台不支持本地文件操作。`              | 在 iOS／Android 应用中运行，检查打包器是否误用了 Web 入口        |
| `本地文件路径无效。`                        | 使用绝对 `file://` URI，正确编码文件名中的 `?`、`#` 等字符       |
| `源文件与目标文件不能相同。`                | 使用不同文件路径，注意 `.`、`..` 和 URI 编码后的等价路径         |
| `目标文件已存在，不能覆盖。`                | 使用尚不存在的目标，避免多个操作同时写入                         |
| `请明确使用 UTF-8 或 base64 读取本地文件。` | 传入 `encoding: 'utf8'` 或 `'base64'`                            |
| `写入内容必须是字符串。`                    | 传入字符串；对象先用 `JSON.stringify()` 序列化                   |
| `目录不能作为单个文件删除。`                | 单文件删除不接受目录；清空目录内容请使用 `clearLocalDirectory()` |
| `本地文件大小不可用。`                      | 检查文件元数据和 RNFS 补丁；未知大小不等于零                     |
| `本地目录清理未完成。`                      | 查看 `status` 和 `failures`，检查权限及清理期间的目录修改        |
| `无法确认本地目录直接子项的归属。`          | 检查子项路径、Unicode 名称和链接，保留实际目录名进行核对         |
| `下载地址、目标或限制参数无效。`            | 使用 HTTP(S) 地址；大小为非负安全整数，超时为正数                |
| `文件下载响应未成功。`                      | 查看 `statusCode`，按服务端要求处理请求或认证                    |
| `下载文件超过大小限制。`                    | 核对 `maxBytes` 和文件大小；错误类型为 `size_limit`              |
| `本地资源公开根目录无效。`                  | 检查 `rootUri`；创建对象时会同步抛出此错误                       |
| `静态服务 SDK 无法安全表示此公开根目录。`   | 目录路径不能包含双引号或以反斜杠结尾                             |
| `文件不在本地资源公开根目录内。`            | 使用 `rootUri` 目录内的文件                                      |
| `本地资源 HTTP 服务正由其他对象持有。`      | 复用已有访问对象，结束使用后统一关闭                             |
| `本地资源 HTTP 服务不可用。`                | 检查原生配置和服务启动错误；再次调用 `getUrl()` 可重试           |
| `本地资源访问已关闭。`                      | 当前对象已开始关闭，不能再获取链接                               |
| `本地资源 HTTP 服务关闭失败。`              | 查看原生日志，确认服务是否仍占用端口                             |

## 安装后仍提示原生模块缺失

按[安装配置](host-setup.md)核对依赖版本和 SDK 补丁，然后重新安装 iOS Pods、编译应用。仅重启 JavaScript 无法更新原生依赖。

存在多份 SDK 依赖时，检查应用、Files 和原生构建实际使用的副本是否均已修正。补丁冲突需先解决，再进行全新安装验证。

## 下载没有总进度，或取消后还有文件

总大小未知时不返回 `totalBytes`。下载是否完成以最终 `status` 为准；进度达到 100% 或目标文件出现都不能代替成功结果。平台超时限制见[文件下载](api/download.md)。

取消后需等待函数返回。函数会在原生任务结束后清理本次文件，清理失败时可能有残留。仅清理确认属于本次失败任务的文件，避免误删其他文件。

## 已取得链接，但 WebView 无法加载

`getUrl()` 不检查文件是否存在。确认文件可读、服务未关闭，并按[本地 HTTP 配置](host-setup.md#本地-http-访问)允许 `127.0.0.1` 的 HTTP 请求。

排查时可在内部日志查看 `cause`，避免将原始 SDK 信息直接展示给用户或发送到外部。
